# بوت تيليجرام الذكي لتحميل الفيديوهات بأعلى جودة (Telegram Video Downloader Bot) 🎬⚡

بوت تيليجرام احترافي، فائق السرعة وسهل الاستخدام، مبني بلغة بايثون لتحميل مقاطع الفيديو من كافة شبكات التواصل الاجتماعي (تيك توك، إنستغرام، يوتيوب، إكس/تويتر، فيسبوك، ريديت، بنترست، وغيرها) بأعلى جودة صوت وصورة متاحة ومطابقة للأصل، مع معالجة ذكية لقيود حجم تيليجرام (50MB).

---

## 🌟 أبرز المميزات

- **أعلى جودة صوت وصورة (100% Original)**: سحب مسارات الفيديو والصوت المنفصلة بأقصى دقة (`bv*+ba/b`) ودمجها عبر `FFmpeg` بتقنية `Lossless Stream Copying` في حاوية MP4 نظيفة وسريعة بدون إعادة تشفير وبدون أي فقدان في الجودة.
- **إدارة ذكية لحدود تيليجرام (50MB)**:
  - فحص دقيق لحجم الملف قبل الرفع لتجنب انهيار البوت.
  - إذا تجاوز الفيديو 48MB بالجودة الفائقة، يقوم المحرك تلقائياً بجلب أفضل جودة تالية تقع تحت حاجز الـ 48MB.
  - إذا كان المقطع طويلاً جداً ويتجاوز الحد بجميع الجودات، يتم إبلاغ المستخدم بلباقة مع إرشاده.
- **تجربة مستخدم فورية وسلسة**:
  - التعرف التلقائي على الروابط بمجرد إرسالها دون الحاجة لكتابة أي أوامر.
  - تحديث حي وتفاعلي لرسالة الحالة:
    `⚡ جاري فحص الرابط...` -> `📥 جاري التحميل بأعلى جودة...` -> `🚀 جاري الرفع إلى تيليجرام...`
  - إرسال الفيديو مع غلاف المقطع (Thumbnail)، المدة الزمنية، والأبعاد الأصلية، وخاصية البث المباشر (Streaming Support).
  - حذف رسالة الانتظار تلقائياً بعد اكتمال الإرسال لتبقى المحادثة نظيفة.
- **كفاءة وأداء عالي ومنع الحظر**:
  - تشغيل عمليات التنزيل الثقيلة داخل خيوط غير متزامنة (`asyncio.to_thread`) لضمان عدم توقف أو تجميد البوت عن خدمة المستخدمين الآخرين.
  - ترويسات طلبات (Headers) و User-Agent واقعي وحديث لتجاوز قيود المواقع.
  - دعم ملف كوكيز اختياري (`cookies.txt`) لتجاوز قيود الحسابات الخاصة على إنستغرام وقيود يوتيوب.
  - تنظيف وحذف فوري للملفات والمجلدات المؤقتة فور اكتمال الإرسال أو عند حدوث خطأ (`finally` blocks).

## 🛠 التقنيات المستخدمة

- **Python 3.11+**
- **aiogram 3.x**: أحدث إصدار من إطار العمل غير المتزامن (Async/Await).
- **yt-dlp**: محرك بايثون أصلي لاستخراج وتنزيل الميديا (Native Module).
- **FFmpeg & imageio-ffmpeg**: لدمج مسارات الصوت والصورة المدمجة تلقائياً دون الحاجة لتثبيت برامج إضافية على النظام.
- **python-dotenv**: لإدارة المتغيرات البيئية وتأمين التوكن.

## 🚀 طريقة التثبيت والتشغيل

### 1. تثبيت المتطلبات
تأكد من وجود بايثون (Python 3.11 فما فوق)، ثم نفّذ الأمر التالي لتثبيت الحزم:

```bash
pip install -r requirements.txt
```

> **ملاحظة بخصوص FFmpeg**: يحتوي المشروع على حزمة `imageio-ffmpeg` التي توفر نسخة جاهزة من FFmpeg تلقائياً على خادمك أو جهازك دون الحاجة لتثبيته يدوياً!

### 2. إعداد التوكن والمتغيرات
قم بإنشاء ملف `.env` بناءً على الملف النموذجي `.env.example`:

```bash
cp .env.example .env
```
*(أو قم بنسخ الملف يدوياً وتسميته `.env`)*

افتح ملف `.env` وضع التوكن الخاص ببوتك المستخرج من [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
MAX_FILE_SIZE_MB=48
DOWNLOAD_DIR=downloads
COOKIES_FILE=cookies.txt
```

### 3. تشغيل البوت

#### الطريقة الأولى: التشغيل المباشر (للتجربة والتطوير)
```bash
python bot.py
```

#### الطريقة الثانية: التشغيل الدائم عبر PM2 (موصى به للاستضافة وسيرفرات VPS)
يحتوي المشروع على ملف إعدادات جاهز `ecosystem.config.js` لتشغيل البوت في الخلفية 24/7 مع إعادة التشغيل التلقائي عند أي توقف أو إعادة تشغيل للسيرفر.

1. **تثبيت PM2 عالمياً** (إذا لم يكن مثبتاً لديك مسبقاً عبر Node.js):
   ```bash
   npm install -g pm2
   ```

2. **تشغيل البوت عبر ملف الإعدادات**:
   ```bash
   pm2 start ecosystem.config.js
   ```

3. **أهم أوامر إدارة البوت في PM2**:
   - عرض حالة البوت واستهلاك الذاكرة:
     ```bash
     pm2 status
     ```
   - متابعة سجلات البوت الحية ومراقبة العمليات (Live Logs):
     ```bash
     pm2 logs telegram-downloader-bot
     ```
   - إعادة تشغيل البوت:
     ```bash
     pm2 restart telegram-downloader-bot
     ```
   - إيقاف البوت:
     ```bash
     pm2 stop telegram-downloader-bot
     ```
   - حفظ التشغيل التلقائي عند إعادة تشغيل السيرفر (Linux / VPS):
     ```bash
     pm2 save
     pm2 startup
     ```

> **ملاحظة لنظام Linux/VPS**: إذا كان أمر بايثون في سيرفرك هو `python3` أو كنت تستخدم بيئة افتراضية (`venv`)، يمكنك تعديل سطر `interpreter` داخل `ecosystem.config.js` إلى `"python3"` أو مسار الـ venv الخاص بك مثل `"./.venv/bin/python"`.

## 🍪 كيفية استخدام ملف الكوكيز (اختياري)

لتجاوز القيود المفروضة على بعض مقاطع يوتيوب أو إنستغرام (مثل المقاطع المقيدة بالعمر أو التي تتطلب تسجيل دخول):
1. قم بتثبيت إضافة للمتصفح مثل **"Get cookies.txt LOCALLY"** (متوفرة لكروم وفايرفوكس).
2. افتح موقع YouTube أو Instagram وأنت مسجل دخولك، ثم صدّر ملف الكوكيز بصيغة Netscape.
3. سمّ الملف `cookies.txt` وضعه في المجلد الرئيسي للمشروع بجانب `bot.py`.
4. سيتعرف البوت تلقائياً على الملف ويستخدمه لتجاوز أي حظر!

## 👑 لوحة تحكم المشرف والتقارير اليومية التلقائية

البوت مجهز بنظام إدارة كامل وقاعدة بيانات SQLite لتسجيل كل عملية بدقة متناهية:

1. **التقرير اليومي الحقيقي التلقائي (Daily Report)**:
   - يرسل البوت يومياً في تمام الساعة **11:00 مساءً** (أو أي ساعة تختارها) رسالة مفصلة للمشرف.
   - يتضمن التقرير:
     - عدد الأشخاص الحقيقيين الذين استخدموا البوت اليوم.
     - عدد الفيديوهات المحمّلة وتوزيعها حسب المنصات (تيك توك، إنستغرام، يوتيوب، إلخ).
     - أسماء ومعرفات الأشخاص الذين حمّلوا اليوم وعدد مقاطع كل منهم والمنصات التي حمّلوا منها.
     - قائمة المستخدمين الذين تواصلوا مع البوت اليوم دون تحميل.
     - إجمالي المشتركين والتحميلات منذ تأسيس البوت.
     - **جميع الأرقام حقيقية 100%** ومستخرجة من قاعدة البيانات مباشرة.
   - **أمر طلب التقرير في أي وقت**: `/report` أو `/تقرير`
   - **أمر ضبط ساعة الإرسال التلقائي**: `/set_report_hour 23` (من 0 إلى 23)

2. **نظام الإذاعة الجماعية (Broadcast / BC)**:
   - يتيح للمشرف إرسال رسائل أو مقاطع فيديو أو صور أو صوتيات لجميع مستخدمي البوت فوراً.
   - طريقة الاستخدام: قم بالرد (Reply) على أي رسالة واكتب `/bc`.

3. **أوامر الإدارة الأخرى**:
   - `/stats`: عرض إحصائيات عدد المشتركين والنشطين.
   - `/id`: استخراج آيدي حسابك ورتبتك.
   - `/addadmin <id>`: ترقية مستخدم لمشرف في البوت.
